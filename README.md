# Торговец из Медового Лога

Уютная фэнтези-игра для телефона про торговое хозяйство. Вы — управляющий: нанимаете крестьян и мастеров на бирже найма, платите жалованье, заключаете и продлеваете договоры, обучаете людей, повышаете в должности и помогаете им с личными целями. Ещё в игре есть стройка во Владениях, гильдия, аукцион, чайный дом, сезонные праздники и сюжетная карьера. Все персонажи — взрослые вымышленные герои.

Игра — статический сайт (HTML, CSS, JS), сервер не нужен. Прогресс сохраняется в браузере (localStorage). Сохранения прежних версий переносятся автоматически.

**Играть:** https://richard-zov.github.io/trader-game/

На телефоне откройте ссылку и выберите «Добавить на главный экран», чтобы запускать игру как приложение.

Необязательный ИИ-чат и озвучка работают через ваш собственный ключ Gemini. Ключ хранится только в вашем браузере.

## v16.0 — наёмная артель
- Работники — свободные наёмные люди: у каждого есть жалованье, договор на 14 дней, настроение и лояльность. Недовольные могут уволиться.
- Общение и забота: разговор, похвала, премия, выходной, подарок, учёба у мастера и повышение (Работник → Старший → Бригадир → Мастер артели).
- Личные цели работников с наградами, панель «Дела управляющего», сезонные праздники.
- Чайный дом вместо прежнего заведения, биржа найма вместо рынка, на аукционе — договоры с мастерами.
