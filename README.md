# Торговец из Медового Лога

Уютная фэнтези-игра для телефона: покупайте, обучайте и продавайте невольников на рынке, развивайте поместье, гильдию и родословные. Все персонажи — совершеннолетние вымышленные герои.

Игра — статический сайт (HTML, CSS, JS), сервер не нужен. Прогресс сохраняется в браузере (localStorage).

**Играть:** https://richard-zov.github.io/trader-game/

На телефоне откройте ссылку и выберите «Добавить на главный экран», чтобы запускать игру как приложение.
